Commentary — how far can the complaint ratio fall?

1 · How much an intervention buys. The upgrade cut the non-outage complaint ratio ~43% — from 29.2% (Apr–May pre) to 16.7% (Jun–Jul) — and the drop landed immediately in June. July holds at 17.1%. An intervention delivers a big one-time step-change; holding it is the discipline.

2 · The idealistic floor. It never reaches zero — a live network always throws off some genuine complaints — but it can fall far below today's 17%. The strongest CSPs here run at ~5–8% (K.H., Sameer Alam, Gaurav). The direction to aim for is single digits; 17% still carries fixable excess. (Absolute target to be set by ops, not by the current best.)

3 · What it holds. Earlier mean-reversion (the Mar–May drift back up after the January wave) says the gap stays closed only with recurring maintenance, not one-off upgrades. Biggest lever = the laggards — MD 24%, Nextia 20%, Speed 20%, THREE STAR 20% run 3–4× the best CSPs; pulling them down moves the average most. Runway so far: 29% → 17% (−43%, banked); the next leg toward single digits is a maintenance-discipline problem, not a capital one.

Method. Base = internet-related tickets (SERVICE_TICKET_MODEL by LCO_ACCOUNT_ID). A ticket is "outage" if its IST time falls in a confirmed >3-device incident window (INCIDENTS, FIRST_FAIL → min(CLOSED_AT, FIRST_FAIL+4h)) — the 4h cap drops ~3,760 never-closed multi-week "incidents" (dead devices) that otherwise delete 95% of tickets. Tiny outages (≤3 devices down) are NOT excluded — only mass outages (>3 devices) count, so complaints during small 1–3 device blips stay in the ratio. Outage data starts 2026-01-08; Nov, Dec, Jan 1–7 use each CSP's own covered-months removal rate. Across covered months 18.7% of complaints are removed as outage-driven.
